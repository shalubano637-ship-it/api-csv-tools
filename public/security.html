Security

Last updated: September 26, 2026

Gateway protections

  • Private and local network targets are blocked.
  • Embedded URL credentials are blocked.
  • Only HTTP/HTTPS and supported ports are allowed.
  • Request URL, header and body size limits are enforced.
  • Rate limiting is applied to public gateway and MCP traffic.
  • Write methods exposed through MCP require explicit confirmation.

Credential safety

Never publish API keys or private tokens in frontend code, GitHub repositories or public screenshots. When using API CSV Tools, send credentials only to services you are authorized to access.

Responsible disclosure

If you discover a security issue, please report it privately through the project's GitHub repository rather than publicly posting credentials, exploit details or sensitive data. Include enough information to reproduce the issue safely.

Scope

Third-party APIs, Cloudflare infrastructure and external services connected through the tool have their own security controls and policies and are outside API CSV Tools' direct control.
