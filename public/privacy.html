Privacy Policy

Last updated: September 26, 2026

API CSV Tools is a browser-based developer utility for API, CSV and JSON workflows. This policy explains the main data-handling practices of the service.

1. Browser-side data

CSV files, JSON documents and API history used by the web interface are designed to be processed or stored locally in your browser unless a feature explicitly sends data through the gateway or to a target API. Browser local storage can be cleared through your browser settings.

2. API requests

When you test an API through the API CSV Tools gateway, the URL, request method, headers and body you submit are transmitted to the gateway and then to the target API you specify. The target API may independently log or process that information under its own privacy policy.

3. Network and security data

The gateway uses Cloudflare infrastructure and rate limiting to operate and protect the service. Network information such as IP address may be processed by infrastructure providers as part of request handling, abuse prevention and security. We do not promise that third-party infrastructure providers retain no logs.

4. Credentials

Do not submit passwords, private tokens, API keys or other secrets unless you understand that they may be transmitted to the target API. API CSV Tools does not ask you to place secrets in source code. Credentials stored in browser-based plugin settings are under your browser's local storage and should be treated as potentially accessible to anyone with access to that browser profile.

5. Third-party services

Requests sent to third-party APIs are governed by those services' own terms and privacy policies. API CSV Tools does not control third-party data practices.

6. Children's privacy

The service is a general developer tool and is not specifically directed at children.

7. Changes

This policy may be updated when the service or its data practices change. The updated version will be posted on this page.

8. Contact

For privacy or security questions, use the project's GitHub repository and issue tracker.
